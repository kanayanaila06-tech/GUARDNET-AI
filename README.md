# 🛡️ GuardNet-AI

### AI-Powered Early Detection of Online Gambling Promotion

GuardNet-AI adalah prototype sistem deteksi dini promosi judi online berbasis Artificial Intelligence.

Sistem menggunakan pendekatan multimodal dengan menggabungkan:

- Text Analysis
- OCR
- Visual Analysis
- Payment Detection
- Multimodal Risk Assessment
- Case Management
- Incident Reporting
- Evidence Integrity

## 🔄 System Workflow

```text
Content
   ↓
Text / OCR / Visual / Payment Analysis
   ↓
Multimodal Risk Fusion
   ↓
Risk Assessment
   ↓
Case
   ↓
Incident Report
